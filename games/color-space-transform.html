Step 1 · 선형 기저변환 (회전)

목표  색 벡터 (R,G,B)를 ① 회색축 방향 성분과 ② 회색축에 수직인 색도평면 성분으로 나누고 싶다. 이를 위해 서로 직교하는 단위벡터 3개(정규직교기저)를 만든다. 각 단계의 “＋ 해설”을 누르면 자세한 풀이가 나옵니다.

① 회색축 방향 n
무채색은 R=G=B, 즉 (a,a,a)=a·(1,1,1) → 방향은 (1,1,1)
크기 |(1,1,1)| = √(1²+1²+1²) = √3
∴ n = (1,1,1)/√3

왜 회색축부터? 색공간을 정리할 때 가장 먼저 필요한 건 “기준이 되는 세로축”입니다. 회색(무채색)은 색기운이 전혀 없고 오직 밝기만 다른 색이므로, 이 축을 기둥으로 삼으면 나머지를 “그 기둥에서 얼마나·어느 방향으로 벗어났는가”로 말할 수 있습니다.

왜 방향이 (1,1,1)인가? 회색은 세 채널이 똑같습니다: 검정(0,0,0), 중간회색(0.5,0.5,0.5), 흰색(1,1,1) … 모두 (a,a,a) 꼴이죠. 이 점들을 이으면 RGB 큐브의 검정→흰색 대각선이 되고, 그 방향벡터가 (1,1,1)입니다.

왜 √3으로 나누나(정규화)? 나중에 “이 축 방향으로 얼마?”를 내적 한 번으로 바로 읽으려면 축이 길이 1이어야 합니다. 3차원에서 길이는 피타고라스로 |(1,1,1)|=√(1²+1²+1²)=√3. 그래서 n=(1,1,1)/√3, 각 성분은 1/√3≈0.577입니다.

② 빨강에서 회색 성분을 빼낸다 → u 그람–슈미트
빨강 eR=(1,0,0)에서 n방향 성분을 제거:
u′ = eR − (eR·n) n
eR·n = (1+0+0)/√3 = 1/√3
(eR·n)n = (1/√3)·(1,1,1)/√3 = (1/3,1/3,1/3)
u′ = (1,0,0) − (1/3,1/3,1/3) = (2/3, −1/3, −1/3)
|u′| = √(4/9+1/9+1/9) = √(6/9) = √6/3
∴ u = u′/|u′| = (2,−1,−1)/√6

큰 그림. 두 번째 축은 색도평면 위에 놓여야 하니 n에 수직이어야 하고, 이왕이면 “빨강 쪽”을 가리키게 하고 싶습니다. 그래서 빨강 벡터에서 시작해, n을 따라 늘어진 부분(그림자)만 잘라내면 남는 건 자동으로 n에 수직이 됩니다. 이것이 그람–슈미트의 핵심 아이디어입니다.

사영(그림자)이란? 어떤 벡터가 n 방향으로 “얼마나 뻗어 있는지”는 내적 eR·n으로 잽니다. 그 양만큼 n을 곱한 (eR·n)n 이 바로 빨강이 회색축 위에 드리운 그림자입니다. 여기서는 (1/3,1/3,1/3).

빼면 왜 수직이 되나? 남은 벡터 u′=eR−(eR·n)n 과 n의 내적을 계산해 보면
u′·n = eR·n − (eR·n)(n·n) = eR·n − (eR·n)·1 = 0.
(n이 단위벡터라 n·n=1인 게 열쇠입니다.) 그래서 항상 수직이 보장됩니다.

결과의 의미. u′=(2/3,−1/3,−1/3). R 성분은 +, G·B 성분은 똑같이 −. 즉 “빨강으로 간다 = 초록·파랑에서 똑같이 멀어진다”는 방향입니다. 마지막으로 길이 √6/3로 나눠 단위벡터 u=(2,−1,−1)/√6를 얻습니다.

③ 나머지 방향 v (n·u 둘 다에 수직) → 외적
v = n × u  (외적은 두 벡터에 모두 수직)
(1,1,1)×(2,−1,−1) = (1·(−1)−1·(−1), 1·2−1·(−1), 1·(−1)−1·2) = (0, 3, −3)
정규화: (0,3,−3)/|(0,3,−3)| = (0,3,−3)/(3√2)
∴ v = (0, 1, −1)/√2
검산  초록 eG=(0,1,0)에 그람–슈미트를 해도 같은 v가 나온다.

왜 외적? 이제 n과 u는 정해졌습니다. 마지막 축은 둘 다에 수직이어야 합니다. 두 벡터에 동시에 수직인 벡터를 즉시 만들어 주는 도구가 바로 외적 n×u입니다(오른손 법칙으로 방향까지 결정).

계산. 외적의 각 성분은 (a₂b₃−a₃b₂, a₃b₁−a₁b₃, a₁b₂−a₂b₁) 공식으로 (1,1,1)×(2,−1,−1)=(0,3,−3). 방향만 중요하므로 길이 3√2로 나눠 v=(0,1,−1)/√2.

이 축의 정체. v의 R 성분은 0, G는 +, B는 −. 즉 v는 초록↔파랑을 가르는 축입니다. 빨강방향(u)과 밝기방향(n)에 모두 수직인 “남은 색차”가 정확히 초록–파랑 대비라는 게 자연스럽죠.

검산의 뜻. 초록에서 출발해 그람–슈미트를 해도 똑같은 v가 나옵니다. 어느 색에서 시작하든 “n·u에 수직인 평면”은 하나뿐이므로, 우리가 만든 기저가 일관됨을 확인해 주는 것입니다.

✓ 직교·정규 확인
n·u = (2−1−1)/√18 = 0   n·v = (0+1−1)/√6 = 0   u·v = (0−1+1)/√12 = 0
|n|=|u|=|v|=1  → 세 벡터는 정규직교기저.

무엇을 확인하나? “정규직교기저”라는 이름 그대로 두 조건입니다. ① 서로 직교: 모든 짝의 내적이 0. ② 정규: 각 벡터의 길이가 1. 위 세 내적이 모두 0으로 떨어지고 길이도 1이니 두 조건을 만족합니다.

왜 중요한가? 이 조건이 성립하면 새 좌표계로의 변환이 순수한 회전(길이·각도·부피 보존)이 됩니다. 늘리거나 찌그러뜨리지 않죠. 그래서 3D 화면에서 Step 1 동안 큐브가 모양을 유지한 채 “회전만” 하는 것입니다. 만약 직교가 아니었다면 큐브가 비틀려 찌그러졌을 겁니다.

＊ 왜 굳이 "직교"인가?
직교이기 때문에 세 성분이 서로 간섭하지 않는다. 밝기를 올리면 n 성분(Lgray)만 커지고 (α,β)는 그대로 → 색상(Hue)이 변하지 않는다. 이것이 "밝기와 색을 분리"하는 수학적 근거다.

직교 = 좌표의 독립성. 축들이 서로 수직이면, 한 축을 따라 움직여도 다른 축의 좌표는 전혀 변하지 않습니다. 서로 “새지” 않는 거죠.

색공간에서의 의미. 그래서 밝기(회색축 성분 Lgray)를 키워도 색도평면 좌표 (α,β)는 그대로입니다. (α,β)가 그대로면 각도 = Hue도 그대로. 즉 “불빛을 밝게 해도 빨강은 여전히 빨강”이라는 우리의 직관이 수학적으로 보장됩니다.

반대로 비직교였다면? 밝기를 바꾸면 색상까지 슬금슬금 흔들려서, 밝기와 색을 따로 조절할 수 없게 됩니다. HSV·HSL이 “밝기(V·L)”와 “색(H)”을 독립 다이얼로 제공하는 것 자체가 이 직교성 덕분입니다.

→ 사영 = 내적
Lgray = (R,G,B)·n = (R+G+B)/√3
α = (R,G,B)·u = (2R−G−B)/√6
β = (R,G,B)·v = (G−B)/√2
이 (α,β)를 극좌표로 바꾼 각도 atan2(β,α) 가 바로 Hue다. Step 1의 선형 부분이 색상을 이미 결정한다.

왜 좌표가 내적인가? 정규직교기저에서는 “어떤 축 방향으로 얼마?”라는 좌표가 그 축 단위벡터와의 내적 하나로 그대로 읽힙니다. 그래서 세 좌표가 (R,G,B)·n, ·u, ·v로 깔끔하게 나옵니다. 이게 위 α·β 공식이 “왜 하필 저 계수(2R−G−B 등)”인지에 대한 답입니다 — 전부 기저벡터 성분에서 나온 것.

극좌표로의 전환. (α,β)는 색도평면 위 한 점의 직교좌표입니다. 이를 극좌표 (반지름, 각도)로 바꾸면
· 각도 θ = atan2(β,α) → Hue(색상)
· 반지름 √(α²+β²) → 채도(색의 진하기)
즉 색상환의 “각도”라는 개념이 여기서 태어납니다.

Step 2로 넘어가며. 여기까지(사영·각도)는 모두 선형·삼각함수라 매끈합니다. 진짜 비선형은 다음 단계의 max·min(V, S)에서 등장하며, 그때 원기둥/육각뿔 모양이 완성됩니다.

핵심 개념 자세히

정의. n = (1,1,1)/√3. RGB 큐브에서 검정(0,0,0)→흰색(1,1,1)으로 이어지는 대각선의 단위 방향벡터입니다. 이 선 위의 점은 모두 R=G=B, 즉 색기운이 없는 무채색(회색)이라 “회색축”이라 부릅니다.

왜 √3으로 나누나(정규화). 방향만 필요하면 (1,1,1)로 충분하지만, 나중에 “이 축 방향으로 얼마?”라는 좌표를 내적 한 번으로 곧장 읽으려면 축의 길이가 정확히 1이어야 합니다. 3차원 길이는 피타고라스로 |(1,1,1)|=√(1²+1²+1²)=√3. 그래서 각 성분이 1/√3(≈0.577)인 단위벡터가 됩니다.

좌표로서의 뜻. 색 벡터를 n에 사영하면 Lgray=(R,G,B)·n=(R+G+B)/√3. 세 채널이 균등하게 1/√3씩 기여하므로, 이 값은 곧 밝기(명도) 성분입니다. 여기서 벗어난 나머지가 “색기운”이 되죠.

“회전축”이라는 말의 정확한 의미. Step 1에서 하는 일은 n이 화면의 수직(위쪽)으로 서도록 공간 전체를 돌리는 것입니다. 이때 헷갈리기 쉬운 점: n 자체가 “돌리는 중심선”은 아닙니다. n은 “세워야 할 목표 기둥”이고, 실제로 도는 중심선(진짜 회전축)은 n을 위쪽 방향으로 옮기는 방향, 즉 n과 up의 외적 n×up 쪽입니다. 정리하면 — n = 정렬 대상(색공간의 중심 기둥), 회전은 그 기둥을 똑바로 세우는 동작.

3D에서 확인. “회색축에서 내려다보기” 버튼을 누르면 이 n을 정면으로 마주 보게 되고, 큐브의 여섯 색 모서리가 정확히 정육각형으로 배열됩니다. 이 육각형이 곧 색상환의 뼈대입니다.

무슨 문제를 푸나. 아무렇게나 놓인(단, 서로 독립인) 벡터 몇 개가 주어졌을 때, 같은 공간을 서로 직각으로 만나는 길이 1짜리 축들로 다시 세우고 싶습니다. 그람–슈미트는 이걸 순서대로 해내는 표준 절차입니다.

단 하나의 아이디어: “그림자 빼기”. 새 벡터에서 이미 만든 축들 방향으로 드리운 그림자(사영)를 모두 빼면, 남는 성분은 그 축들에 자동으로 수직이 됩니다.

q₁ = a₁ / |a₁|
q₂ = ( a₂ − (a₂·q₁)q₁ ) 를 정규화
q₃ = ( a₃ − (a₃·q₁)q₁ − (a₃·q₂)q₂ ) 를 정규화

왜 수직이 보장되나(핵심 증명). 만든 벡터를 q₁과 내적해 보면
( a₂ − (a₂·q₁)q₁ )·q₁ = a₂·q₁ − (a₂·q₁)(q₁·q₁) = a₂·q₁ − (a₂·q₁)·1 = 0.
q₁이 단위벡터(q₁·q₁=1)인 것이 이 소거의 열쇠입니다.

우리 문제에 적용. a₁=(1,1,1) → q₁=n. a₂=빨강(1,0,0) → 사영 한 번 빼서 q₂=u. 세 벡터 중 둘을 이렇게 얻었고, 마지막 하나는 3차원의 특권인 외적으로 대신 구합니다(③번 참고).

순서·시작 벡터가 결과를 정한다. 어떤 벡터를 첫 축으로 잡느냐에 따라 최종 기저가 달라집니다. 우리는 “빨강을 색도평면의 기준 방향으로 삼겠다”는 의도로 eR을 골랐고, 그래서 u가 빨강 쪽을 가리키게 된 것입니다.

정의와 쓸모. 3차원 두 벡터 a, b의 외적 a×b는 a와 b 둘 다에 수직인 새 벡터입니다. “이미 두 축이 있는데 거기 수직인 세 번째 축이 필요하다” — 바로 우리 상황이라 외적이 최적의 도구입니다.

성분 공식(행렬식 기억법).

a×b = ( a₂b₃ − a₃b₂,  a₃b₁ − a₁b₃,  a₁b₂ − a₂b₁ )
우리 계산: (1,1,1)×(2,−1,−1) = (0, 3, −3)

방향 — 오른손 법칙. 오른손 네 손가락을 a에서 b로 감아쥘 때 엄지가 가리키는 쪽이 a×b입니다. 그래서 순서가 중요합니다: b×a = −(a×b) (방향이 정반대).

크기 — 평행사변형 넓이. |a×b| = |a||b|sinθ 로, a와 b가 만드는 평행사변형의 넓이와 같습니다. 두 벡터가 나란하면(θ=0) 0이 됩니다. 특히 a, b가 서로 수직인 단위벡터면 |a×b| = 1·1·sin90° = 1 → 결과가 자동으로 단위벡터입니다.

왜 여기서 유용한가. n과 u는 이미 “수직인 단위벡터”이므로 n×u는 곧바로 세 번째 단위 축이 됩니다. (해설 계산에서는 정규화 안 된 (1,1,1)×(2,−1,−1)로 잡아 크기 3√2로 나눴을 뿐, 원리는 같습니다.) 결과 v=(0,1,−1)/√2.

검산 습관. 나온 v가 정말 맞는지 v·n=0, v·u=0 을 확인하세요. 둘 다 0이면 “두 축에 수직”이 확인된 것입니다.
