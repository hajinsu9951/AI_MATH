인공지능이란 무엇일까

인공지능(Artificial Intelligence)은 인식·학습·추론·행동과 같은 인간의 지적 능력을 컴퓨터로 구현하는 기술입니다. 이 이름은 1956년 다트머스 회의에서 존 매카시가 처음 제안했습니다.

오늘날의 인공지능은 데이터 · 모델 · 학습의 세 요소로 작동합니다. 데이터는 경험의 기록이고, 모델은 입력을 출력으로 바꾸는 함수이며, 학습은 데이터에 가장 잘 맞는 함수를 찾아가는 과정입니다. 즉, 인공지능을 이해하는 열쇠는 우리가 이미 배운 함수 개념입니다.

인공지능을 수학의 눈으로 보면 입력 x ──▶ 모형(함수) f ──▶ 출력 y 학습 = 데이터 (x, y)를 가장 잘 설명하는 함수 f 를 찾는 일
학습 목표는 어떤 활동으로 이어지나 — 목표 ① [12인수01-01]은 전개 탭 ②에서 — 같은 함수를 규칙기반(A)과 학습기반(B)으로 각각 만들어 보며 "규칙을 찾는 주체가 누구인가"의 차이를 몸으로 익힙니다. 목표 ② [12인수01-02]는 전개 탭 ①·③에서 — 튜링 테스트 판별 게임과 역사 타임라인으로 각 사건에 숨은 수학(논리 연산, 부등식, 미분, 행렬, 확률)을 확인합니다.

단계 2 · 정리 — 무엇이 판별의 단서였나

게임을 마친 뒤 열어 보세요. 판별의 단서는 크게 세 갈래였습니다.

  • 불완전함 — 오타·말버릇·감정의 요동은 사람의 흔적입니다. 규칙은 "틀리는 법"까지 흉내 내기 어렵습니다.
  • 구체적 경험 — 급식·검산·산책 같은 개인의 체험은 데이터로 뭉뚱그려지지 않은 "한 사람의 기록"입니다.
  • 회피와 반복 — 같은 문형의 반복(ELIZA), 어려운 질문 회피(유진 구스트만)는 규칙기반 챗봇의 전형적 전략입니다.

그런데 마지막 문항(생성형 AI)은 판별이 어려웠지요? 활동지에 내가 쓴 판별 기준 2가지와 "그 기준이 최신 AI에도 통할까"를 적어 봅시다.

단계 3 · 정의 확인 — 튜링 테스트 (1950) — 앨런 튜링은 "기계가 생각할 수 있는가?"라는 물음을 "대화만으로 기계와 사람을 구별할 수 있는가?"라는 판별 문제로 바꾸었습니다. 2014년에는 챗봇 '유진 구스트만'이 심사위원 33%를 속여 통과 논란이 있었는데, 13세 외국인 소년이라는 설정으로 어려운 질문을 회피하는 전략을 썼습니다. 최신 생성형 AI의 답변은 판별이 훨씬 어렵습니다 — 여러분이 틀렸다면 바로 그것이 오늘의 교훈입니다.
탐구 목표 — 같은 함수를 "사람이 규칙을 쓰는 방식"과 "기계가 데이터에서 찾는 방식"으로 각각 만들어 보고 차이를 설명합니다. 진행 순서: 단계 1 관찰(A·B 실험) → 단계 2 정리(비교) → 단계 3 정의 확인(기계학습). 아래 단계 카드를 순서대로 열어 보세요.

단계 1 · 관찰 — 같은 함수, 두 가지 만들기

왼쪽(A)은 사람이 규칙을 알고 직접 쓰는 기존 프로그램 방식, 오른쪽(B)은 데이터에서 기계가 규칙을 찾는 기계학습 방식입니다. 두 방식 모두 결과는 "함수"라는 점에 주목하세요.

단계 2 · 정리 — 두 방식 비교하기

실험을 마친 뒤 열어 보세요. A와 B에서 "규칙을 찾은 주체"가 누구였는지 비교합니다.

  • A 규칙기반 — 규칙을 아는 것은 사람. 사람이 규칙을 코드로 옮겨 적으면 함수 f가 완성됩니다.
  • B 학습기반 — 규칙을 아는 사람이 없습니다. 데이터 (x, y)를 모아 규칙(함수)을 추측한 것은 바로 여러분 — 기계학습이 하는 일을 여러분이 체험한 것입니다.
  • 라운드 3의 교훈 — 잡음이 있으면 "완벽한 규칙"은 없습니다. 가장 잘 맞는 함수를 찾을 뿐이며, 이것이 이후 배울 "오차 줄이기(최적화)"의 출발점입니다.
단계 3 · 정의 확인 — 왜 학습이 필요할까? — 기계학습(Machine Learning)은 규칙을 사람이 적는 대신, 데이터 (x, y)에서 규칙(함수 f)을 컴퓨터가 스스로 찾게 하는 방법입니다. 라운드 3에서 보았듯 현실 데이터에는 잡음이 있고, 손글씨 인식처럼 규칙을 말로 다 적을 수 없는 문제가 대부분입니다. 규칙을 쓸 수 없을 때, 데이터에서 함수를 찾는 것 — 그것이 기계학습입니다.

단계 3 · 정의 확인 — 겨울은 왜 오고, 봄은 왜 왔나 — AI 겨울은 기대가 무너져 연구비와 관심이 끊긴 시기(1974~1980, 1987~1993)를 말합니다. 1차 겨울의 계기는 수학적 한계의 증명(단층 퍼셉트론은 XOR을 표현하지 못한다)이었고, 봄을 되돌린 것도 새로운 수학(다층 구조 + 미분을 이용한 역전파, GPU의 행렬 연산)이었습니다. 즉 AI의 역사는 "수학의 한계 발견 → 새 수학으로 돌파"의 반복입니다.

심화 — 사건마다 숨은 수학 한눈에 보기

연표의 사건과 수학 개념을 짝지어 정리했습니다. 시험 대비 겸 훑어 보세요.

  • 1943 인공 뉴런 — 논리 연산 (∧, ∨, ∼)
  • 1958 퍼셉트론 — 가중합과 부등식 (w₁x₁+w₂x₂ ≥ θ)
  • 1969 XOR의 벽 — 연립부등식의 모순 (직선 하나로 분리 불가)
  • 1986 역전파 — 미분 (변화율로 오차 줄이기)
  • 2012 AlexNet — 합성곱과 행렬 연산
  • 2016 알파고 — 확률과 보상 (강화학습)
  • 2022 생성형 AI — 조건부확률 (다음 단어 예측)

Q1. 기계가 '지능이 있다'고 판단하는 기준은 무엇이어야 하는가?

튜링은 "생각하는가"라는 답할 수 없는 물음을 "대화만으로 사람과 구별할 수 있는가"라는 판별 가능한 문제로 바꾸었습니다. 즉 기준은 기계의 내부가 아니라 겉으로 드러난 행동입니다. 다만 판별 게임에서 보았듯 최신 생성형 AI 앞에서 이 기준은 흔들립니다 — 기준을 정하는 일 자체가 여전히 열린 물음입니다.

Q2. AI의 역사는 왜 붐과 겨울을 반복했는가?

겨울은 수학적 한계(단층 퍼셉트론은 XOR을 표현하지 못한다는 부등식의 모순)와 과장된 기대의 붕괴에서 왔고, 봄은 언제나 새로운 수학(다층 구조와 미분을 이용한 역전파, GPU의 행렬 연산, 확률과 보상)으로 돌아왔습니다. AI의 역사는 "수학의 한계 발견 → 새 수학으로 돌파"의 반복입니다.

오늘의 한 줄: 인공지능은 입력 x를 출력 y로 잇는 함수 f를 데이터에서 찾는 일입니다. 활동지에 "AI의 겨울은 왜 왔고, 무엇이 녹였는가"를 한 줄로 써 보세요.
