단계 3 · 정의 확인 — 오차와 손실함수

실제 측정값 yi (i = 1, 2, …, n)와 추세선 f(x) = ax 로 구한 예측값 axi 에 대하여

오차 : y₁ − ax₁, y₂ − ax₂, …, yn − axn
손실함수 : L(a) = { (y₁ − ax₁)² + (y₂ − ax₂)² + ⋯ + (yn − axn)² } ÷ n

라 합니다. L 은 손실을 뜻하는 Loss의 첫 글자이며, 같은 함수를 비용함수(Cost function)·목적함수(Objective function)라고도 부릅니다. 고등학교 교육과정에서는 추세선이 f(x) = ax 인 일변수 손실함수만 다룹니다.

예 1. 세 점 (1, 2), (2, 3), (3, 5)에 대하여 L(a) = {(2 − a)² + (3 − 2a)² + (5 − 3a)²} ÷ 3 = (14a² − 46a + 38) ÷ 3 입니다.
예 2. 위 여섯 점에 대하여 L(a) = (88a² − 330a + 319) ÷ 6 입니다.

h 에 0을 대입할 수는 없습니다(분모가 0). 그러나 0에 가까워질 때 값이 어디로 가는지는 말할 수 있습니다. 이것이 함수의 극한이고, 그 값이 접선의 기울기입니다.

단계 2 · 정리 — 식으로 확인하기

{ f(t+h) − f(t) } ÷ h = { (t+h)² − 4(t+h) + 5 − (t² − 4t + 5) } ÷ h = (2th + h² − 4h) ÷ h = 2t − 4 + h

여기서 h → 0 이면 값은 2t − 4 입니다. 곧 f′(t) = 2t − 4 이고, t = 1 일 때 f′(1) = −2, t = 2 일 때 f′(2) = 0, t = 3 일 때 f′(3) = 2 입니다.

일반적으로 이차함수 f(x) = ax² + bx + c 에 대하여 f′(t) = 2at + b 입니다. 이 한 줄만 있으면 어떤 이차함수의 어느 점에서든 경사를 계산할 수 있습니다.

단계 3 · 정의 확인 — 함수의 극한 · 접선 · 미분계수

함수의 극한. 함수 f(x) 에서 x 의 값이 a 가 아니면서 a 에 한없이 가까워질 때 f(x) 의 값이 일정한 값 α 에 한없이 가까워지면, f(x) 는 α 에 수렴한다고 하고 α 를 x = a 에서 f(x) 의 극한값이라 하며 기호로 limx→a f(x) = α 와 같이 나타냅니다.

접선. 곡선 y = f(x) 위의 두 점 P(t, f(t)), Q(t+h, f(t+h)) 에 대하여 h → 0 이면 Q 가 곡선을 따라 P 에 한없이 가까워지고, 직선 PQ 는 점 P 를 지나는 어떤 직선 l 에 한없이 가까워집니다. 이 l 을 점 P 에서의 접선, P 를 접점이라 합니다.

미분계수. 이차함수 y = f(x) 의 그래프 위의 점 P(t, f(t)) 에서 접하는 접선의 기울기를 x = t 에서의 미분계수라 하고 기호로 f′(t) 와 같이 나타냅니다. { f(t+h) − f(t) } ÷ h 를 평균변화율, 그 h → 0 극한을 순간변화율이라고도 합니다.

함숫값이 없어도 극한값은 있을 수 있습니다. 예를 들어 f(x) = (x² − 2x) ÷ x 는 x = 0 에서 함숫값이 없지만, x ≠ 0 에서 f(x) = x − 2 이므로 limx→0 f(x) = −2 입니다.

단계 3 · 정의 확인 — 한 줄 계산 |1 − 2Ak|

L(a) = A·a² + B·a + C 이면 L′(a) = 2A·a + B 이므로 an+1 − α = (1 − 2Ak)(an − α)  (α 는 꼭짓점의 a좌표)

즉 최솟값까지의 거리가 매 걸음 |1 − 2Ak| 배가 됩니다. 이 값이 1 보다 작으면 수렴, 1 이면 영원히 진동, 1 보다 크면 발산합니다. 음수이면 좌우를 번갈아 뛰는 지그재그가 됩니다.

1 − 2Ak 의 값a 의 움직임
0 < 1 − 2Ak < 1한 방향으로 곧게 수렴
1 − 2Ak = 0단 한 번에 꼭짓점 도달 (k = 1/(2A))
−1 < 1 − 2Ak < 0좌우를 번갈아 뛰며 수렴 (지그재그)
1 − 2Ak = −1같은 두 점을 영원히 왕복 (진동, k = 1/A)
|1 − 2Ak| > 1점점 멀어짐 (발산)

이 표가 곧 29차시의 답입니다. 아이스티 데이터는 A = 820 이므로 발산하지 않는 학습률의 상한이 1/A ≒ 0.00122 에 불과합니다. 그래서 29차시 실습에서 k = 0.0005 를 쓰고, k = 0.1 은 곧바로 폭발합니다.
