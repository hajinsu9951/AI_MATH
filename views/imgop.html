단계 2 · 중간 정리 — 255를 넘으면 컴퓨터는 어떻게 할까

8비트 회색조에서 한 칸이 가질 수 있는 값은 0 이상 255 이하의 정수뿐입니다. 계산 결과가 이 범위를 벗어나면 범위 안으로 잘라 넣습니다. 이것을 클리핑이라고 합니다.

  • 0보다 작아지면 → 0(검은색보다 더 검은 색은 없습니다)
  • 255보다 커지면 → 255(흰색보다 더 흰 색은 없습니다)

직접 확인해 보세요. ① 원본 사진에서 가장 밝은 곳(달)을 클릭해 숫자 창을 그 자리로 옮기고, ② 미션 ④(2배)를 누른 뒤 ③ [클리핑 0~255] 체크를 끄면 숫자 창에 붉은 수가 나타납니다 (예: 245 → 490). 그 수는 8비트 이미지로 저장할 방법이 없는 값입니다.

되돌릴 수 없다는 점도 중요합니다. 255로 잘린 칸들은 원래 280이었는지 460이었는지 알 수 없게 되어, k를 다시 0.5로 낮춰도 원본으로 돌아오지 않습니다.

단계 3 · 정의 확인 — 행렬의 덧셈·뺄셈·실수배

같은 꼴의 두 행렬 A = (aij), B = (bij)에 대하여

① A ± B 의 (i, j) 성분 = aij ± bij
② kA 의 (i, j) 성분 = k · aij

모든 성분이 1인 행렬을 J 라 하면, 밝기 변환은 다음 두 줄로 정리됩니다.

A₁ = A + tJ (t > 0 이면 밝아지고, t < 0 이면 어두워진다)
A₁ = kA (k > 1 이면 밝아지고, 0 < k < 1 이면 어두워진다)

컬러 이미지라면 같은 식을 R, G, B 세 행렬에 똑같이 적용합니다. 성분이 정수가 아니면 반올림·올림·버림으로 정수로 맞춥니다.

[R 채널만]은 G와 B를 0으로 만드는 변환입니다. 즉 G = O, B = O(영행렬)로 바꾸는 것과 같습니다. 그러면 빨강 성분이 큰 곳만 밝은 빨강으로 남습니다.

단계 2 · 중간 정리 — 회색조의 조건은 R = G = B

빨강·초록·파랑의 농도가 모두 같으면 검정과 흰색 사이의 무채색이 됩니다. 그래서 회색조 변환의 목표는 R₁ = G₁ = B₁이 되도록 세 행렬을 하나의 값으로 모으는 것입니다.

평균식 R₁ = G₁ = B₁ = ⅓(R + G + B)
가중치식 R₁ = G₁ = B₁ = 0.299R + 0.587G + 0.114B

단계 3 · 정의 확인 — 반전은 ‘255에서 빼기’ 한 줄

모든 성분이 255인 행렬을 255J 라 하면, 반전된 이미지는

A₁ = 255J − A

입니다. 한 칸만 보면 y = 255 − x, 즉 기울기가 −1인 일차함수입니다. 활동 1의 변환 곡선에서 [반전]을 켜면 선이 오른쪽 아래로 내려가는 것을 확인할 수 있습니다.

같은 변환을 두 번 하면 255 − (255 − x) = x 이므로 원래대로 돌아옵니다. 클리핑과 달리 반전은 정보를 잃지 않는 변환입니다.

단계 1 · 관찰 기록 — 계수의 합은 왜 언제나 1인가

표를 보면 A의 계수 + B의 계수 = 1이 한 번도 깨지지 않습니다. 합이 1보다 크면 사진이 전체적으로 밝아지고(흰색 쪽으로 몰림), 1보다 작으면 어두워집니다.

합을 1로 묶어 두었기 때문에 ‘섞임’만 일어나고 밝기는 유지됩니다. 그래서 α 하나만 정하면 나머지는 자동으로 1 − α 로 정해집니다.

단계 2 · 중간 정리 — 수직선의 내분점과 사진 합성은 같은 식

수직선 위의 두 점 A(a), B(b)에 대하여 선분 AB를 m : n 으로 내분하는 점 P의 좌표는

P = (m·b + n·a) / (m + n) = (n/(m+n))·a + (m/(m+n))·b

여기서 α = n/(m+n) 이라 하면 P = αa + (1 − α)b 이고, 두 계수의 합은 언제나 1입니다.

사진 합성은 이 계산을 모든 픽셀에서 한꺼번에 하는 것입니다. 수 하나가 행렬 하나로 바뀌었을 뿐, 식의 모양은 완전히 같습니다.

C = αA + (1 − α)B (0 ≤ α ≤ 1)

단계 3 · 정의 확인 — 오버랩(디졸브)의 수학

두 이미지 X, Y를 나타낸 세 행렬을 각각 RX, GX, BX 와 RY, GY, BY 라 하고, 가중치 α (0 ≤ α ≤ 1)에 대하여

R = αRX + (1 − α)RY
G = αGX + (1 − α)GY
B = αBX + (1 − α)BY

라 놓으면 합성된 이미지 Z를 얻습니다. α가 1에 가까울수록 X가, 0에 가까울수록 Y가 선명합니다. α를 1에서 0까지 천천히 바꾸면 X 위로 Y가 겹치며 넘어가는 오버랩(디졸브)이 됩니다.

영화에서 한 장면이 흐려지며 다음 장면이 또렷해지는 전환이 바로 이 식입니다.

지금까지의 변환(kA + tJ, 255J − A, αA + (1−α)B)은 칸의 값만 바꾸었을 뿐, 칸의 자리는 그대로였습니다. 이번에는 자리 자체를 바꿉니다. 행렬 A 의 행과 열을 서로 맞바꾼 행렬을 만들면, 사진은 어떻게 될까요?

예상을 고르면 아래 실험판이 열립니다.

실험판 — 3 × 3 숫자표부터, 사진까지

먼저 작은 표에서 확인합니다. 왼쪽 표의 칸을 누르면 그 성분이 AT 의 어느 자리로 옮겨 가는지 두 표에 함께 표시됩니다.

A 의 성분

AT 의 성분

칸을 눌러 보세요 — A 의 (i, j) 성분은 AT 의 (j, i) 자리로 갑니다.

같은 규칙을 사진(행렬)에 그대로 적용해 봅니다.

눌러 본 버튼 0 / 4 — 세 가지 이상 눌러 보면 아래 단계 토글이 열립니다.

↓ 아래 세 단계는 버튼 3가지 이상을 눌러 본 뒤에 열립니다.

단계 1 · 관찰 기록 — 전치는 어느 선을 기준으로 뒤집는가

사진이 왼쪽 위 ↔ 오른쪽 아래를 잇는 대각선(주대각선)을 축으로 접힌 것처럼 뒤집혔습니다. 위아래 뒤집기도, 좌우 뒤집기도 아닙니다.

주대각선 위의 칸, 곧 (1,1)·(2,2)·(3,3) … 은 자기 자리에 그대로 남습니다. i = j 이면 (i, j) 와 (j, i) 가 같은 자리이기 때문입니다.

②를 눌러 보면 두 번 전치하면 원래대로 돌아옵니다. (AT)T = A 입니다.

③과 ④의 결과는 완전히 같습니다. 값을 바꾸는 연산(반전)과 자리를 바꾸는 연산(전치)은 순서를 바꾸어도 결과가 같습니다.

단계 2 · 중간 정리 — 꼴(행·열의 개수)은 어떻게 바뀌나

정사각행렬이 아니면 꼴도 함께 바뀝니다. m × n 행렬 A 의 전치행렬 AT 는 n × m 행렬입니다.

A 의 꼴Aᵀ 의 꼴이미지에서의 뜻
3 × 33 × 3정사각 사진 — 크기는 그대로, 방향만 바뀜
2 × 33 × 2가로로 긴 사진이 세로로 긴 사진이 됨
1 × 4 (행벡터)4 × 1 (열벡터)가로줄 한 줄이 세로줄 한 줄이 됨

위 실험판의 [표 바꾸기]에서 2 × 3 직사각행렬을 골라 두 표의 모양을 직접 비교해 보세요.

대칭행렬은 AT = A 가 되는 특별한 정사각행렬입니다. 주대각선을 기준으로 마주 보는 값이 서로 같으므로 전치해도 아무것도 달라지지 않습니다. [표 바꾸기]의 세 번째 항목에서 확인해 보세요.

단계 3 · 정의 확인 — 전치행렬

정의. m × n 행렬 A = (aij) 의 행과 열을 서로 바꾸어 얻은 n × m 행렬을 A 의 전치행렬이라 하고 AT 로 나타냅니다.

AT 의 (i, j) 성분 = A 의 (j, i) 성분

예를 들어

A = [[1, 2, 3], [4, 5, 6], [7, 8, 9]] 일 때
AT = [[1, 4, 7], [2, 5, 8], [3, 6, 9]]

성질. ① (AT)T = A    ② (A + B)T = AT + BT    ③ (kA)T = kAT

②·③ 때문에 「반전한 뒤 전치」와 「전치한 뒤 반전」의 결과가 같았습니다 — 모든 성분이 1인 행렬 J 는 JT = J 이므로 (255J − A)T = 255J − AT 이기 때문입니다.

이미지에서. 전치는 사진을 주대각선을 축으로 뒤집는 변환입니다. 여기에 좌우 뒤집기를 한 번 더 하면 사진을 90° 회전시킬 수 있습니다.

STEP 3 · 정리

오늘의 핵심 3줄

  1. 이미지의 밝기 변환은 행렬의 덧셈 A + tJ 와 실수배 kA 이고, 반전은 뺄셈 255J − A 입니다.
  2. 계산 결과가 0~255를 벗어나면 0 또는 255로 잘라 넣습니다(클리핑). 잘린 값은 되돌릴 수 없습니다.
  3. 두 이미지의 합성 C = αA + (1 − α)B 는 수직선 위 내분점과 같은 식이며, 두 계수의 합은 언제나 1입니다.

자세히 보기 — 예시 답안

「나만의 필터 한 장」 — 수식으로 설명되는 사진 보정

사진 앱의 버튼을 누르는 대신, 내가 고른 수식으로 사진을 바꾸고 그 이유를 수학으로 설명합니다. 계산의 정확성보다 변환을 행렬의 연산으로 해석할 수 있는가가 중심입니다.

수행 방법
① 내가 찍은 사진 1장을 고르고, 학습지에 함께 제공되는 엑셀 파일(활동4 xlsx)의 [데이터] 시트에 회색조 값을 붙여 넣습니다(또는 제공된 예시 데이터를 그대로 씁니다).
② 서로 다른 세 가지 수식을 만들어 세 장의 결과를 얻습니다. 예: B₁ = 1.3A, B₂ = A − 40J, B₃ = 255J − A.
③ 각 결과에 대해 대표 픽셀 3칸을 골라 원본값 → 계산식 → 결과값을 손으로 적습니다. 255를 넘거나 0보다 작아진 칸이 있으면 표시하고 어떻게 처리했는지 씁니다.
④ 친구의 사진 1장을 받아 C = αA + (1 − α)B 로 합성하고, α를 세 가지(예: 0.2, 0.5, 0.8)로 바꿔 결과 세 장을 만듭니다.
⑤ 세 장 중 가장 자연스러운 α를 고르고, 왜 그 값이 좋았는지 수직선 위 내분점의 위치로 설명합니다.
제출물
· 원본 1장 + 변환 3장 + 합성 3장의 결과 이미지(캡처 또는 인쇄)
· 대표 픽셀 계산표 1장(원본값 · 계산식 · 결과값 · 클리핑 여부)
· “내가 고른 α는 ___이고, 이 값은 수직선에서 A와 B를 ___ : ___ 로 내분하는 점이다”를 포함한 결론 3~5문장
· (선택) 엑셀 파일 제출

결과 이미지의 미적 완성도가 아니라, 수식과 결과의 대응을 설명할 수 있는지를 봅니다. 클리핑이 일어난 칸을 스스로 찾아내는 학생은 성취기준을 충분히 도달한 것으로 볼 수 있습니다.
