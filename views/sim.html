활동 1 · 7~8분

"비슷하다"를 우리가 먼저 정해 봅시다

문제 사진 속 말풍선에 들어갈 문장을 한 문장으로 써 봅시다. 그리고 옆 친구가 쓴 문장과 내 문장이 얼마나 비슷한지 수 하나로 나타낸다면, 무엇을 세어야 할까요?

상황 1 — 축구를 하다 무릎이 까진 친구와 그 옆에서 말을 거는 친구(말풍선 1개). 상황 사진은 저장소 로컬 자산(assets/situations/)으로만 제공합니다.

Text_mining으로 학급 문장 모으기 ↗

담은 문장은 이 기기에 저장되어(공통 말뭉치) 7·8차시에서 모은 문장과 함께 쓰입니다. Text_mining은 선생님이 안내하는 방코드를 입력하면 학급 전체 문장이 한곳에 모입니다 — 활동지 「활동 2(유사도분석)」 1~4번 문항이 그 화면과 1:1로 대응합니다.

    내 기준 제안하기 — "두 문장이 비슷한 정도를 어떻게 수로 나타낼까요?" 아래에 내 생각을 적고, 보기 칩 가운데 하나를 눌러 그 기준으로 계산한 값을 확인해 봅시다.

    단계 1 · 관찰겹치는 단어를 세어 보면 무슨 일이 일어나나요?

    문장 ①과 ②는 겹치는 단어가 2개, ①과 ③도 2개로 같은 값이 나옵니다. 그런데 ①·②는 둘 다 "보건실에 가자"고 하고, ③은 "괜찮으니 계속하자"고 합니다. 개수만 세는 기준은 문장이 길수록 무조건 유리해지고, 뜻이 반대여도 구분하지 못합니다.

    단계 2 · 정리그래서 무엇이 더 필요한가요?

    겹치는 단어의 개수는 ⓐ 문장 길이에 휘둘리고 ⓑ 단어를 몇 번 썼는지를 반영하지 못합니다. 8차시에서 우리는 이미 문장을 빈도수 벡터로 바꾸는 법을 배웠습니다.

    벡터로 바꾸면 문장은 공간 위의 한 점이 되고, 그때부터는 수학이 이미 가지고 있는 두 개의 자를 쓸 수 있습니다 — 점과 점 사이의 거리, 그리고 화살표와 화살표가 이루는 각입니다.

    단계 3 · 정의 확인유사도란 무엇인가

    두 텍스트 데이터 사이의 유사한 정도를 수치로 나타낸 것을 유사도라고 합니다.

    유사도를 정량화하는 방법에는 집합을 이용하여 정의하는 자카드 유사도(12차시)와, 벡터를 이용하여 정의하는 유클리드 유사도·코사인 유사도(오늘)가 있습니다. 어떤 유사도를 쓸지는 정해진 정답이 없으며, 분석하는 대상과 목적에 따라 선택합니다.

    활동 2 · 8~10분

    거리로 재기 — 유클리드 유사도

    문제 세 학생 A, B, C의 주말 스마트폰 사용 시간(단위: 시간)을 조사했습니다. A와 가장 비슷하게 사용한 학생은 누구일까요? 먼저 눈으로 어림잡아 예상해 보고, 그 다음 계산으로 확인합시다.

    내 예상:

    예상을 고르기 전에는 계산 결과와 단계 카드가 열리지 않습니다.

    학생SNS게임영상 시청
    아홉 칸 모두 직접 고칠 수 있습니다(0~10, 소수 첫째 자리까지).
    3차원 데이터를 2차원 면에 투영해서 봅니다.
    비교 대상:

    지금 보고 있는 면: SNS × 영상 시청

    A(실선) B(긴 점선) C(짧은 점선)

    계산 과정

    직접 계산해 봅시다 — d(A, C)의 값을 소수 둘째 자리까지 입력하세요.

    단계 1 · 관찰세 거리를 모두 구해 봅시다

    d(A, B) = √2 ≈ 1.41 　 d(A, C) = √11 ≈ 3.32 　 d(B, C) = √9 = 3.00

    A에게 가장 가까운 학생은 B입니다. 캔버스에서도 A와 B의 끝점을 잇는 점선이 가장 짧습니다.

    단계 2 · 정리이 값은 무엇을 비교한 것인가

    거리는 각 항목을 얼마나 비슷한 양으로 썼는가를 비교합니다. A와 B는 SNS 6시간·5시간, 영상 2시간·3시간처럼 절대적인 사용량 자체가 비슷합니다.

    반면 C는 A와 사용 습관이 비슷해 보이지만 전체 사용량이 절반이라 거리가 멀어졌습니다. 그래서 유클리드 유사도는 양(크기)이 중요한 상황에 알맞습니다.

    단계 3 · 정의 확인유클리드 유사도

    두 텍스트 데이터를 나타내는 위치벡터의 끝점 사이의 거리를 유클리드 유사도라고 하고, 두 텍스트 데이터 A, B를 각각 벡터 a=(a₁, a₂, …, aₙ), b=(b₁, b₂, …, bₙ)으로 나타낼 때 기호로 d(a, b)와 같이 나타냅니다.

    d(a, b) = |b − a| = √((b₁−a₁)² + (b₂−a₂)² + … + (bₙ−aₙ)²)

    유클리드 유사도의 값이 0에 가까울수록 두 텍스트 데이터가 유사하다고 판단합니다. 또한 d(a, a) = 0입니다.

    예시 1 a=(0, 1, 1), b=(1, 1, 2), c=(2, 0, 1)일 때 d(a,b)=√2, d(a,c)=√5, d(b,c)=√3이므로 A와 B가 가장 유사합니다.
    예시 2 두 점 A(1, 4), B(5, 1)에 대해 d = √(4² + (−3)²) = 5입니다.

    출처 — 씨마스 「인공지능 수학」 Ⅱ 단원 p.73, 동아출판 「인공지능 수학」 Ⅱ 단원 p.68 서술을 재구성

    읽을거리 — 거리에 이름을 남긴 사람, 유클리드

    우리가 오늘 쓴 "두 점 사이의 거리"는 사실 여러 가지 거리 중 하나입니다. 선분의 길이로 거리를 정의하는 방식을 고대 그리스의 수학자 유클리드의 이름을 따 유클리드 거리라고 부릅니다.

    인공지능에서는 이 밖에도 각 성분의 차이의 절댓값을 모두 더하는 맨해튼 거리, 서로 다른 자리의 개수를 세는 해밍 거리(18차시), 겹치는 정도를 비율로 보는 자카드 유사도(12차시) 등을 상황에 맞게 골라 씁니다. 유사도는 세 가지뿐이 아니며, 문제의 목적이 자를 고릅니다.

    출처 — 씨마스 「인공지능 수학」 Ⅱ 단원 p.73 지식 Plus, 연수교재 합본 「여러 가지 유사도」 참고 자료를 재구성

    활동 3 · 8~10분

    방향으로 재기 — 코사인 유사도

    문제 같은 표를 그대로 두고 질문만 바꾸겠습니다. "A와 사용 습관(패턴)이 가장 비슷한 학생"은 누구일까요? 사용 시간의 총량이 아니라 SNS·게임·영상에 시간을 나누어 쓴 비율이 비슷한 학생을 찾는 것입니다.

    내 예상:

    예상을 고르기 전에는 계산 결과와 단계 카드가 열리지 않습니다.

    비교 대상:

    방향으로 재기 · 지금 보고 있는 면: SNS × 영상 시청

    끝점을 잇던 점선이 사라지고, 원점을 중심으로 두 화살표 사이에 사잇각 호가 그려집니다. 호 옆의 각과 값은 지금 보고 있는 두 항목의 면에서 잰 것이고, 오른쪽 계산 과정의 C(a, b)는 세 항목 전체로 구한 값입니다.

    회전은 미리보기입니다 — 지금 보고 있는 두 항목의 면에서만 각과 값을 다시 계산해 보여 주며, 표의 값은 바뀌지 않습니다. 각이 커지면 값이 1에서 멀어지고, 사잇각이 0°가 되면 정확히 1이 됩니다.

    계산 과정

    직접 계산해 봅시다 — C(B, C)의 값을 소수 둘째 자리까지 입력하세요.

    단계 1 · 관찰값이 1이 나왔습니다

    C(A, C) = 1.00 — 두 화살표가 완전히 같은 방향입니다. 실제로 C=(3, 1, 1)은 A=(6, 2, 2)의 정확히 절반이므로, 원점에서 같은 반직선 위에 놓입니다. 사잇각이 0°이므로 코사인 값은 1입니다.

    한편 C(A, B) ≈ 0.98로 B도 매우 비슷하지만 1에는 못 미칩니다.

    단계 2 · 정리거리와 답이 갈렸습니다

    활동 2에서 거리로 재었을 때 A와 가장 가까운 학생은 B였습니다. 그런데 방향으로 재니 답이 C로 바뀌었습니다.

    C는 A와 전체 사용량은 절반이지만 시간을 나누어 쓴 비율이 똑같기 때문입니다. 두 답이 모두 옳습니다 — 다만 묻는 질문이 다릅니다.

    단계 3 · 정의 확인코사인 유사도

    두 텍스트 데이터를 나타내는 벡터의 방향이 비슷한 정도를 코사인 유사도라고 하고 기호로 C(a, b)와 같이 나타냅니다.

    C(a, b) = (a₁b₁ + a₂b₂ + … + aₙbₙ) ÷ (√(a₁²+…+aₙ²) × √(b₁²+…+bₙ²)) = (성분끼리 곱해 더한 값) ÷ (두 벡터의 크기의 곱)

    이 값은 두 벡터가 이루는 각 θ에 대한 cos θ의 값과 같음이 알려져 있습니다. 따라서 값이 1에 가까울수록(θ가 0°에 가까울수록) 유사하고, 0에 가까울수록(θ가 90°에 가까울수록) 유사하지 않다고 판단합니다.

    빈도수 벡터는 성분이 모두 0 이상이므로 코사인 유사도는 0 이상 1 이하의 값을 가집니다. 또한 C(a, a) = cos 0° = 1입니다.

    예시 a=(1, 0), b=(3, 0), c=(3, 2), d=(0, 2)일 때 → a와 b: 0°, 값 1 　a와 c: 약 33.7°, 값 3√13⁄13 ≈ 0.83 　a와 d: 90°, 값 0

    읽을거리 — 음식점 리뷰 하나를 긍정·부정으로 나누기

    어느 음식점 리뷰에 나오는 긍정 단어와 부정 단어를 모아 전체집합을 만들었습니다.

    U = {청결하다, 빠르다, 맛있다, 많다, 불편하다, 별로다, 불친절, 최악} 긍정 단어 p = (1, 1, 1, 1, 0, 0, 0, 0) 부정 단어 n = (0, 0, 0, 0, 1, 1, 1, 1)

    리뷰 X "이 음식점은 매장이 청결하고 서비스도 빨랐지만, 음식이 별로고 직원들도 불친절해서 불편했습니다."
    리뷰 X의 빈도수 벡터 x = (1, 1, 0, 0, 1, 1, 1, 0)

    거리로 재면 d(x, p) = √5 ≈ 2.24, d(n, x) = √3 ≈ 1.73 → 부정 쪽이 더 가깝습니다.
    방향으로 재면 C(x, p) = 2 ÷ (√5 × 2) ≈ 0.45, C(n, x) = 3 ÷ (√5 × 2) ≈ 0.67 → 부정 쪽이 더 큽니다.

    두 방법 모두 리뷰 X를 '부정'으로 분류합니다. 이렇게 문장 하나를 긍정·부정 단어 벡터와 견주는 방식이 12차시 감성 분석의 출발점입니다.

    단계 · 정의 확인L2 정규화

    벡터의 각 성분을 그 벡터의 크기로 나누어 크기가 1인 벡터로 고치는 것을 L2 정규화라고 합니다.

    정규화한 벡터의 끝점은 원점에서 거리가 1인 곳에 모이므로, 2차원에서는 모두 단위원 위에 놓입니다. 이때 크기 정보는 사라지고 방향 정보만 남기 때문에, 정규화한 두 벡터의 거리로 재는 것은 사실상 방향을 비교하는 것과 같아집니다.

    선택 심화거리와 코사인은 사실 같은 이야기였습니다평가 제외

    크기가 1인 두 벡터 â, b̂ 사이의 거리를 제곱해 보면

    d(â, b̂)² = |â|² + |b̂|² − 2 × (성분끼리 곱해 더한 값) = 1 + 1 − 2 C(a, b) = 2 − 2 C(a, b)

    이므로 d(â, b̂) = √(2 − 2 C(a, b)) 입니다. 코사인 유사도가 커질수록 정규화한 두 벡터의 거리는 작아집니다. 실제로 C(A, B) ≈ 0.9783이므로 √(2 − 2×0.9783) ≈ 0.21로, 위에서 구한 값과 정확히 일치합니다.

    3일 기록표(손글씨 또는 표 캡처) 1장 / 두 유사도의 계산 과정이 보이는 계산지 1장(식 → 대입 → 값 순서) / 결론 한 문단(5~7문장): 두 결과의 비교 + 어느 유사도를 택할지와 그 이유
    평가 관점
    A수준 두 유사도를 정확히 계산하고, 결과가 갈리는 이유를 데이터의 크기·패턴 특성과 연결하여 설명하며, 상황에 맞는 유사도를 근거를 들어 선택한다.
    B수준 두 유사도를 정확히 계산하고, 어느 쪽이 더 유사한지 판단한다.
    C수준 한 가지 유사도를 정확히 계산한다. [12인수02-03]
    ※ 두 유사도의 값의 크기를 직접 비교해 우열을 매긴 서술은 감점 요소입니다.
    확장(선택)
    항목을 네 개에서 여섯 개로 늘려 보고, 항목이 늘었을 때 어느 유사도의 판단이 더 안정적인지 관찰해 봅시다.
