단계 1 · 관찰 — 무엇이 분모를 키웠나요?

세 후기의 단어집합은 모두 원소가 5개로 같습니다. 그런데 J 값은 달랐습니다. A와 B는 ‘맛있다’와 ‘상큼하다’ 하나씩만 달랐으므로 합집합이 6으로 작았고, A와 C는 ‘오늘/내일’, ‘맛있다/새콤하다’ 두 자리가 달라 합집합이 7로 커졌습니다. 분자가 줄고 분모가 커지는 일이 동시에 일어나기 때문에, 단어 하나 차이가 값에 생각보다 크게 작용합니다.

단계 2 · 정리 — 계산 결과
쌍교집합n(A∩B)n(A∪B)J소수
A와 B{나, 오늘, 사과, 먹다}45 + 5 − 4 = 64/6 = 2/3≒ 0.67
A와 C{나, 사과, 먹다}35 + 5 − 3 = 73/7≒ 0.43
B와 C{나, 사과, 먹다}35 + 5 − 3 = 73/7≒ 0.43

따라서 J(A, B)가 가장 크므로 후기 A와 B가 가장 유사합니다. 눈으로 고른 답과 같았나요? A와 C, B와 C의 값이 정확히 같다는 점도 눈여겨보세요. ‘오늘/내일’과 ‘맛있다/새콤하다’처럼 다른 자리의 개수가 같으면 자카드 유사도도 같아집니다. 자카드는 어떤 단어가 다른지가 아니라 몇 개가 겹치는지만 보기 때문입니다.

단계 3 · 정의 확인 — 자카드 유사도란 무엇인가

두 텍스트 데이터에 모두 포함된 단어의 비율, 곧 두 단어집합의 교집합의 원소 개수를 합집합의 원소 개수로 나눈 값을 자카드 유사도라 하고, 기호로 J(A, B)와 같이 나타냅니다.

J(A, B) = n(A∩B) / n(A∪B) = n(A∩B) / { n(A) + n(B) − n(A∩B) }

값의 범위는 0 이상 1 이하이며, 1에 가까울수록 유사, 0에 가까울수록 유사하지 않다고 판단합니다. 특히 A = B이면 J = 1, A∩B = ∅이면 J = 0 입니다.

자카드 유사도는 스위스의 식물학자 폴 자카드(Paul Jaccard, 1868~1944) 가 서로 다른 지역의 식물 종 구성이 얼마나 겹치는지를 재기 위해 고안한 값입니다. 백 년 뒤 같은 식이 문장의 단어를 세는 데 쓰이고 있습니다.

단계 1 · 관찰 — 왜 J 값이 이렇게 작을까요?

문장에 긍정 단어가 다섯 개나 들어 있어도 J(P, A)는 0.42밖에 되지 않았습니다. 분모가 문장의 단어 수만이 아니라 사전 전체의 단어 수까지 더한 값이기 때문입니다. 사전이 커질수록 분모가 커지므로 J 값은 작아집니다.

그래서 감성 점수는 0.9, 0.8 같은 큰 값이 아니라 0.1~0.3 정도의 작은 값에서 판정이 갈립니다. 뒤에 나올 k = 0.25가 왜 ‘꽤 높은 기준’인지 여기서 미리 짐작해 보세요.

단계 2 · 정리 — 예시 문장 세 개의 계산

(가) 음식점 리뷰 X — "이 음식점은 매장이 청결하고 넓어서 편하게 식사할 수 있어요. 게다가 음식량도 많고 맛있어요. 하지만 서비스가 불친절한 점은 별로였어요."

X = {청결하다, 넓다, 편하다, 많다, 맛있다, 불친절, 별로다}, n(X) = 7

  • P∩X = {청결하다, 넓다, 편하다, 많다, 맛있다} → J(P, X) = 5 / (10+7−5) = 5/12 ≒ 0.42
  • N∩X = {불친절, 별로다} → J(N, X) = 2 / (10+7−2) = 2/15 ≒ 0.13
  • 감성 점수 = 5/12 − 2/15 = 17/60 ≒ 0.28
    반올림한 0.42와 0.13을 먼저 빼면 0.29가 나옵니다. 분수끼리 뺀 뒤 마지막에 한 번만 반올림해야 정확합니다.

A = {요즘, 공부, 조금, 힘들다, 피곤, 그래도, 잘하다, 해내다, 싶다}, n(A) = 9

  • P∩A = {잘하다} → J(P, A) = 1 / (10+9−1) = 1/18 ≒ 0.06

단계 토글 — 관찰 · 정리 · 정의 확인

단계 1 · 관찰 — 어디에서 판정이 바뀌었나요?

k를 0.25에서 천천히 내리다 보면, 문장 B는 k = 0.20 이하가 되는 순간 ‘중립’에서 ‘부정’으로 바뀝니다. 문장 A는 k = 0.06 이하에서 ‘부정’이 되고, 문장 X는 k = 0.28 이하일 때만 ‘긍정’입니다. 곧 각 문장에는 자신의 판정이 뒤집히는 고유한 k값이 있고, 그 값은 바로 감성 점수의 절댓값입니다.

단계 2 · 정리 — k는 무엇을 조절하는가

k는 중립이라고 부르기로 한 구간의 반지름입니다. k가 크면 중립 구간 (−k, k)가 넓어져 어지간한 문장은 다 ‘중립’이 되고, k가 작으면 구간이 좁아져 작은 기울기에도 긍정·부정 판정이 내려집니다.

그래서 k를 정하는 일은 계산이 아니라 선택입니다. 상담 챗봇처럼 놓치면 위험한 상황에서는 k를 낮추어 예민하게(위험 신호를 잘 잡도록) 만들고, 광고 문구 자동 분류처럼 잘못 알리면 곤란한 상황에서는 k를 높여 신중하게 만듭니다. 5차시에서 정확도의 기준을 어디에 두느냐가 결론을 바꿨던 것과 같은 구조입니다.

단계 3 · 정의 확인 — 판정 부등식

문장의 단어집합을 A, 감성 사전을 P, N이라 하고 양수 k를 임계값이라 할 때

  • J(P, A) − J(N, A) ≥ k 이면 긍정
  • −k < J(P, A) − J(N, A) < k 이면 중립
  • J(P, A) − J(N, A) ≤ −k 이면 부정

으로 분류합니다. 일반적으로 k의 값은 0.25를 적용합니다.

단계 토글 — 관찰 · 정리 · 정의 확인

단계 1 · 관찰 — 단어를 뺐더니 무슨 일이 일어났나요?

‘지치다’를 사전에서 빼면 N의 원소가 10개에서 9개로, 교집합이 3개에서 2개로 줄어듭니다.

J(N, B) = 3/15 = 0.20 → 2/(9+8−2) = 2/15 ≒ 0.13

감성 점수는 −0.20에서 −0.13으로 0보다 가까워집니다. 단어 하나가 빠졌을 뿐인데 부정 신호가 약해진 것입니다. 만약 k = 0.15로 정해 두었다면, 이 문장은 ‘부정’에서 ‘중립’으로 바뀌어 상담 선생님께 연결되지 않습니다.

단계 2 · 정리 — 사전이 결과를 만든다

감성 분석의 결과는 사전과 기준선이라는 두 개의 사람 선택 위에 놓여 있습니다. 사전을 어떻게 짓느냐에 따라 같은 문장의 점수가 달라지고, 기준선을 어디에 두느냐에 따라 같은 점수의 판정이 달라집니다.

그래서 감성 분석의 결과는 정답이 아니라 해석이 필요한 자료입니다. 실제 연구에서는 국립국어원 사전 뜻풀이를 분석해 만든 KNU 한국어 감성 사전처럼 수만 개 단어를 담은 사전을 쓰지만, 그런 사전조차 "하나도 지루하지 않았다" 같은 문장은 놓칩니다(마중 퀴즈 질문 3).

단계 3 · 정의 확인 — 감성 분석이란

인공지능이 텍스트를 분석하여 그 안의 감정을 분류하고 감성을 파악하는 방법을 감성 분석이라고 합니다. 분석 방식에는 긍정·중립·부정으로 극성을 구분하는 방식과, 기쁨·슬픔·놀람·화남·두려움·혐오 등으로 감정을 분류하는 방식이 있습니다. 오늘 우리가 한 것은 앞의 방식이며, 그중에서도 사전과 집합만으로 판단하는 단어 기반 감성 분석입니다.

STEP 3 · 정리 (8분)

오늘의 핵심 3줄

  1. 자카드 유사도는 두 단어집합의 교집합의 원소 개수 ÷ 합집합의 원소 개수이며, 언제나 0 이상 1 이하입니다.
  2. 문장의 단어집합 A와 감성 사전 P, N에 대해 J(P, A) − J(N, A) 를 구하면 그 문장이 어느 쪽으로 기울었는지 하나의 수로 나타낼 수 있습니다.
  3. 그 수를 임계값 k 와 견주어 긍정·중립·부정을 정하며, 사전과 k는 사람이 정하는 값입니다.

「우리 반 감성 사전 만들기」 — 급식 리뷰 감성 분석기

오늘 만든 사전과 기준선을 우리 학교 이야기에 그대로 얹어 봅니다. 계산의 정확성보다 유사도의 개념을 실제 상황에 적용할 수 있는가가 이 과제의 중심입니다.

수행 방법
① 우리 학교 급식(또는 매점·학교 앞 분식집) 후기를 10건 이상 모읍니다. 직접 쓰거나, 친구들에게 한 줄씩 받거나, 학급 게시판에 올라온 글을 옮겨 적어도 좋습니다 (개인을 특정할 수 있는 이름·별명은 지우고 옮깁니다).
② 모은 후기에서 감성을 드러내는 단어를 뽑아 긍정 집합 P와 부정 집합 N을 각각 8개 이상 만듭니다. 어느 쪽에 넣을지 모둠원과 의견이 갈린 단어는 따로 표시해 둡니다.
③ 12차시 웹 도구(senti)에 사전을 입력하고 후기 10건을 차례로 분석하여, 후기별 n(A), J(P,A), J(N,A), 감성 점수, 판정을 표로 정리합니다(소수 둘째 자리까지).
④ k값을 두 가지(예: 0.25와 0.10)로 각각 판정해 보고, 결과가 달라진 후기를 표시합니다.
⑤ 사람이 읽고 매긴 판정(모둠원 3명의 다수결)과 AI의 판정을 비교해 몇 건이 일치했는지 셉니다.

텍스트 분석 형성평가 : 2단원(7~12차시) 전체를 아우르는 지필 형성평가지입니다. 12차시 마무리 또는 13차시 프로젝트 직전에 배부합니다. 2단원 전체 평가지는 이 카드 한 곳에만 둡니다.
